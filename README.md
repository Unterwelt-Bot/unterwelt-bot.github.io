# unterwelt-bot.github.io

Öffentliche Vorstellung des Discord-Bots Hades (GitHub Pages: `index.html`, kein Jekyll – `.nojekyll`). Handgeschrieben; enthält nur, was auch im Einführungsvideo gesagt wird: keine Adressen, Links ins Heimnetz, IDs oder Namen von Personen. Die eigentliche Dokumentation liegt privat im Repo [`doku`](https://github.com/Unterwelt-Bot/doku) und wird **nicht** automatisch hierher veröffentlicht.

Einrichten: Repo auf *public* stellen (auf dem Free-Plan geht Pages nur für öffentliche Repos), *Settings → Pages → Source: Deploy from a branch*, Branch `main`, Ordner `/ (root)`. Den Platzhalter `YOUTUBE_LINK_EINTRAGEN` in `index.html` durch den Link zum Referat ersetzen.
